# @shelter/api-client

TypeScript client generated by Orval from the backend OpenAPI document (architecture §4.2).

Never edit `src/generated/` by hand. After any API contract change, run from the repo root:

```sh
pnpm api:generate
```

This builds `Shelter.Host` in Release with `-p:ExportOpenApi=true` (writes `openapi.json` here), then runs Orval (`orval.config.ts`). Both `openapi.json` and `src/generated/` are committed; CI regenerates and fails on any diff.

## Output

| Import                            | Contents                                                         |
| --------------------------------- | ---------------------------------------------------------------- |
| `@shelter/api-client/hooks/<tag>` | TanStack Query hooks + fetch functions, one file per OpenAPI tag |
| `@shelter/api-client/model`       | Request/response types                                           |
| `@shelter/api-client/zod/<tag>`   | Zod schemas (reuse in React Hook Form)                           |
| `@shelter/api-client/http`        | `ApiError`, `ProblemDetails` (hand-written, `src/http/`)         |

The OpenAPI tag is the backend module's route prefix, and hook names come from the endpoint's `.WithName(...)` (e.g. `GetPlatformPing` → `useGetPlatformPing`).

Every call goes through `src/http/fetcher.ts`: same-origin cookies, JSON bodies returned directly, and any non-2xx response thrown as `ApiError` with the server's ProblemDetails (`status`, `title`, `correlationId`, …).
